## 📌 Overview
This repository contains my solutions for the **Week 4 Database Assignment** in the PLP Academy Database Systems module. The project demonstrates practical proficiency in writing structured SQL queries using aggregate functions, multi-column grouping, sorting, and row-limiting clauses against a relational database (`payments`, `customers`, and `orderdetails` tables).

---

## 🎯 Learning Objectives
- Apply SQL aggregate functions (`SUM()`, `AVG()`, and `MAX()`) to summarize transactional and customer data.
- Structure and filter grouped datasets using the `GROUP BY` clause.
- Sort query outputs chronologically and numerically using `ORDER BY`.
- Restrict result sets to top records using `LIMIT`.
